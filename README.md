## Proyecto


Nombre de la app: SmartNotes AI

Descripcion del proyecto


smartnotes ai es una aplicacion diseñada para ayudar a organizar y comprender mejor los apuntes realizados, la aplicacion va a permitir al usuario tomar una foto de sus notas escritas a mano o en un documento, y automaticamente convierte esa imagen en texto digita.

una vez que el texto es extraido, la aplicacion generara un resumen con las ideas mas importanes, facilitando la comprension 

¿Cómo funciona?

1. El usuario sube una imagen de sus apuntes.
2. La aplicación utiliza inteligencia artificial para reconocer el texto en la imagen.
3. Luego, procesa ese texto y genera un resumen automático.
4. Finalmente, muestra al usuario el texto detectado y su resumen.
